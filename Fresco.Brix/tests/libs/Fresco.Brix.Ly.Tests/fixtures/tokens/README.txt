Token-stream parity fixtures
============================

Each <name>.tokens.tsv is the token stream python-ly v0.9.10 (the reference
checkout the Fresco.Brix.Ly port must match) produced for the adjacent
<name>.ly document, generated by tools/lexprobe/gen-token-fixtures.py.
The first line records the mode ly.lex.guessMode chose; every following line
is pos<TAB>end<TAB>python module<TAB>class<TAB>text (JSON-encoded).

The .ly documents come from CodeBrix.LilyPort/tests/regression (GPL, same
repository — real scores and regression inputs across the tokenizer's
surface: headers, drums, lyrics, markup, figured bass, chord mode, grace
music, tuplets, dynamics, books, scheme-in-markup, quotes, and two real
compositions), plus four small synthetic documents (sample-*.{html,texi,scm,
lytex}) exercising the html, texinfo, scheme and latex modes.

TokenStreamParityTests replays every fixture through the port and compares
token for token. Regenerate with the tool after changing the probe set; never
hand-edit a .tokens.tsv.

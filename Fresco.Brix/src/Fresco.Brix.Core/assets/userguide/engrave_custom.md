=== Custom mode ===

The *Engrave (Custom)* dialog ({key_engrave_custom}) gives you detailed access
to all aspects of an engraving run.

There is no engraver to choose: the dialog names the one built into the
program, and its LilyPond compatibility, at the top. What you can set is the
engraving mode — *Preview*, *Publish*, *First System Only* or *Layout
Control* — whether intermediate output files are deleted afterwards, whether
the source code is embedded, and any additional options to pass to the
engraver.

Output is SVG pages, and MIDI where a score asks for it. Press *Run LilyPort*
to engrave.

=== Documentation ===

{appname} comes with the LilyPond manuals built in. They are engraved copies of
the documentation for the LilyPond release the built-in engraver is compatible
with, and they are installed with the program: there is nothing to download and
no documentation directory to configure.

Under *Documentation* preferences you can choose which manual the
Documentation browser opens on, and how it starts up.

The manuals are shown in {appname}'s own paged viewer, the same one the Music
View uses, with each manual's own table of contents beside it. Press
{key_context} with the cursor in your document to look the word under it up in
the manuals.

A manual can also be handed to the program you normally read documents with:
press *Open* in the Documentation browser's toolbar. Which program that is, is
set under {helpers}.
